МОИ ПАРЫ — ВЕРСИЯ БЕЗ ПАПКИ DIST

1. Распакуй архив.
2. Открой свой репозиторий на GitHub.
3. Выбери Add file → Upload files (Добавить файл → Загрузить файлы).
4. Выдели ВСЕ файлы из распакованного архива и загрузи их в корень репозитория.
   Загружай сами файлы, а не ZIP и не папку.
   index.html, app.mjs, model.mjs, style.css и vercel.json должны быть рядом.
5. Нажми Commit changes (Сохранить изменения).
6. В Vercel импортируй репозиторий и нажми Deploy.

Настройки Vercel:
- Framework Preset: Other.
- Root Directory: корень репозитория.
- Output Directory: . (одна точка, не dist).
- Build Command и Install Command: пусто.
- Переменные окружения не нужны.
Настройки уже записаны в vercel.json.
Если Vercel ранее был настроен на dist, убери эту старую настройку.

На iPhone: открой новую ссылку в Safari → Поделиться → На экран Домой.
